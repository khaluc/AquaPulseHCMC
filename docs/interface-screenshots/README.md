# AquaPulse interface screenshots

Ten screenshots from the running AquaPulse interface, shown in English.

The sample observations, reporters, and community activities are simulated. The images retain the yellow sample-data banner so viewers can identify the demo content.

The controls use English. Local place names, source text, and some seeded demo notes remain in Vietnamese.

Image 02 shows a successful backend analysis using the existing Kimi `kimi-k3` cache. Image 04 uses a different photo of discarded tyres at a rocky water's edge. The current backend detects one tyre with YOLO11n and returns a Kimi photo description. YOLO11s-seg also runs, but returns no water masks for this image. Its VisText-Mosquito photo belongs to the training split and illustrates the interface rather than held-out evaluation. No observation was submitted or mission claimed while capturing these images.

Image 04 source: `data/images/train/vistext_dfbc63fc4d2863a7.jpg`, original filename `1-2-_jpg.rf.f6f585332e8d2f96d40eba243669f908.jpg`. The project source manifest records VisText-Mosquito V2 under CC BY 4.0 (DOI: `10.17632/rtsfh7jh7p.2`).
